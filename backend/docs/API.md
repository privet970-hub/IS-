Optimize Routes\n\n**Endpoint:** `POST /optimization/optimize`\n\n**Description:** Optimize delivery routes for multiple vehicles using Google OR-Tools.\n\n**Request Body:**\n\n```json\n{\n  \"vehicles\": [\n    {\n      \"id\": \"v_001\",\n      \"name\": \"Large Truck #001\",\n      \"vehicle_type\": \"large\",\n      \"capacity\": 20000,\n      \"fuel_consumption\": 8.5,\n      \"fuel_cost_per_liter\": 1500,\n      \"start_location_id\": \"depot\",\n      \"end_location_id\": null\n    }\n  ],\n  \"stops\": [\n    {\n      \"id\": \"depot\",\n      \"name\": \"Seoul Distribution Center\",\n      \"latitude\": 37.5665,\n      \"longitude\": 126.9780,\n      \"demand\": 0\n    },\n    {\n      \"id\": \"stop_001\",\n      \"name\": \"Customer A\",\n      \"latitude\": 37.4979,\n      \"longitude\": 127.0276,\n      \"demand\": 5000,\n      \"arrival_time\": null,\n      \"departure_time\": null,\n      \"service_time\": 0\n    },\n    {\n      \"id\": \"stop_002\",\n      \"name\": \"Customer B\",\n      \"latitude\": 37.5665,\n      \"longitude\": 126.9780,\n      \"demand\": 3000\n    }\n  ],\n  \"start_depot_id\": \"depot\",\n  \"end_depot_id\": null,\n  \"time_limit_seconds\": 30\n}\n```\n\n**Request Parameters:**\n\n| Field | Type | Required | Description |\n|-------|------|----------|-------------|\n| vehicles | Array | Yes | List of available vehicles |\n| stops | Array | Yes | List of delivery/pickup stops |\n| start_depot_id | String | Yes | ID of starting depot (must be in stops) |\n| end_depot_id | String | No | ID of ending depot (defaults to start_depot_id) |\n| time_limit_seconds | Integer | No | Optimization time limit (default: 30) |\n\n**Vehicle Object:**\n\n| Field | Type | Required | Description |\n|-------|------|----------|-------------|\n| id | String | Yes | Unique vehicle identifier |\n| name | String | Yes | Vehicle name/plate number |\n| vehicle_type | String | Yes | Type: small, medium, large, xlarge |\n| capacity | Float | Yes | Maximum capacity in kg |\n| fuel_consumption | Float | Yes | Fuel consumption in L/100km |\n| fuel_cost_per_liter | Float | Yes | Fuel cost in KRW per liter |\n| start_location_id | String | Yes | Starting location ID |\n| end_location_id | String | No | Ending location ID (if different) |\n| max_driving_hours | Integer | No | Maximum driving hours (default: 10) |\n\n**Stop Object:**\n\n| Field | Type | Required | Description |\n|-------|------|----------|-------------|\n| id | String | Yes | Unique stop identifier |\n| name | String | Yes | Stop name |\n| latitude | Float | Yes | Latitude coordinate |\n| longitude | Float | Yes | Longitude coordinate |\n| demand | Float | No | Weight/volume demanded (kg) |\n| arrival_time | Integer | No | Time window start (seconds) |\n| departure_time | Integer | No | Time window end (seconds) |\n| service_time | Integer | No | Service duration (seconds) |\n\n**Success Response (200 OK):**\n\n```json\n{\n  \"success\": true,\n  \"message\": \"Route optimization completed successfully\",\n  \"routes\": [\n    {\n      \"vehicle_id\": \"v_001\",\n      \"vehicle_name\": \"Large Truck #001\",\n      \"stops\": [\n        {\n          \"stop_id\": \"stop_001\",\n          \"stop_name\": \"Customer A\",\n          \"arrival_time\": 0,\n          \"departure_time\": 0,\n          \"demand\": 5000,\n          \"cumulative_distance\": 12.5,\n          \"cumulative_fuel_consumption\": 1.06,\n          \"cumulative_cost\": 1590\n        }\n      ],\n      \"total_distance\": 25.3,\n      \"total_fuel_consumption\": 2.15,\n      \"total_cost\": 3225,\n      \"total_demand\": 5000,\n      \"utilization_rate\": 25.0\n    }\n  ],\n  \"total_distance\": 25.3,\n  \"total_fuel_consumption\": 2.15,\n  \"total_cost\": 3225,\n  \"unserved_stops\": [],\n  \"optimization_time_ms\": 1234\n}\n```\n\n**Response Fields:**\n\n| Field | Type | Description |\n|-------|------|-------------|\n| success | Boolean | Whether optimization succeeded |\n| message | String | Status message |\n| routes | Array | List of optimized routes |\n| total_distance | Float | Total distance in km |\n| total_fuel_consumption | Float | Total fuel consumption in liters |\n| total_cost | Float | Total fuel cost in KRW |\n| unserved_stops | Array | List of stops not assigned to any vehicle |\n| optimization_time_ms | Integer | Time taken for optimization in ms |\n\n**Route Object:**\n\n| Field | Type | Description |\n|-------|------|-------------|\n| vehicle_id | String | Vehicle identifier |\n| vehicle_name | String | Vehicle name |\n| stops | Array | Ordered list of stops for this vehicle |\n| total_distance | Float | Distance for this route in km |\n| total_fuel_consumption | Float | Fuel consumption for this route in liters |\n| total_cost | Float | Total fuel cost for this route in KRW |\n| total_demand | Float | Total demand served in kg |\n| utilization_rate | Float | Capacity utilization percentage |\n\n**Error Response (400/422 Bad Request):**\n\n```json\n{\n  \"success\": false,\n  \"message\": \"At least one vehicle is required\",\n Optimization Service Health Check\n\n**Endpoint:** `GET /optimization/health`\n\n**Description:** Check if the optimization service is operational.\n\n**Response (200 OK):**\n\n```json\n{\n  \"status\": \"healthy\",\n  \"service\": \"route-optimization\",\n  \"version\": \"0.1.0\"\n}\n```\n\n---\n\n### 3. API Status\n\n**Endpoint:** `GET /status`\n\n**Description:** Get general API status.\n\n**Response (200 OK):**\n\n```json\n{\n  \"status\": \"operational\",\n  \"version\": \"0.1.0\",\n  \"service\": \"IS- API\"\n}\n```\n\n---\n\n## Status Codes\n\n| Code | Meaning |\n|------|----------|\n| 200 | Success |\n| 400 | Bad request (validation error) |\n| 422 | Unprocessable entity (missing required fields) |\n| 500 | Internal server error |\n\n## Error Handling\n\nAll errors are returned with a JSON body containing:\n\n```json\n{\n  \"detail\": \"Error message\"\n}\n```\n\n## Rate Limiting\n\nCurrently not implemented.
